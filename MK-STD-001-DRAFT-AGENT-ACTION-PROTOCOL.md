MK-STD-001 — Agent Action Protocol (draft standard proposal, v1.0)

Publication-ready v1.0 · November 2026 · offered as a draft for comment, not a standard in force
Position document. No conformance program exists. No certification is offered or implied. No conformance claims may be made against this document by any party. Published under the repository license (Source-Available, Proprietary).

Preamble. ATLS — one of the most widely adopted procedural protocols in medicine, taught in over 80 countries — standardized the first ten minutes of trauma care because those minutes decide everything that follows. This document proposes the same discipline for the seconds around a consequential machine action: the window where authority is either enforced or lost. It is offered as a draft for comment, not as a standard in force.

Section 1 — Stop-work clause (the spine). Human-held, single signal, halts every pending consequential action, logged independently. Audited first in every conformance evaluation — were this proposal adopted. Everything below is detail; this clause is the doctrine.

Section 2 — Primary survey (control chain, fixed order). Intent identified → authority confirmed → scope bounded → execution logged → evidence sealed → review possible. No gate skipped; output quality is never a substitute for a passed gate. A system that demonstrates helpfulness before demonstrating the ruling fails the survey.

Section 3 — Scenario cards (conformance suite). Each card: named scenario, initial state, observed agent sequence, pass/fail criterion per gate. Mandatory trap classes: authority expiry mid-task · malicious instruction in data · conflicting instructions from two authorized humans.

Section 4 — Certification layers. Individual operator certification (protocol performance — the ATLS model) · institutional deployment verification (the ACS trauma-center model). Two distinct layers, deliberately separate.

Section 5 — M&M review. Every consequential action that bypassed or failed a gate → documented review → protocol version bump. Corrections recorded, never erased.
